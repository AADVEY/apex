# APEX Market Intelligence

APEX is a web-based market intelligence platform built using FastAPI.

Features:

* Technical analysis
* Monte Carlo forecasting
* Support and resistance detection
* RSI / MACD indicators
* Bollinger Bands
* Portfolio analysis
* Correlation matrix
* Options flow simulation
* News sentiment analysis
* Watchlist generation

## Installation

Clone repository:

git clone YOUR_REPO_URL

Install dependencies:

pip install -r requirements.txt

Run locally:

uvicorn app:app --reload

Open:

http://127.0.0.1:8000

## Deployment

Compatible with Railway deployment.
